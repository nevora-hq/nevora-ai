# サイト画像 生成プロンプト集(NEVORA AI)

トップページで使う写真素材(ヒーロー1枚・セクションバンド2枚・カテゴリカード12枚=計15枚)を
ChatGPTで生成するためのプロンプト集。

## 使い方

1. 下記プロンプトをそのままChatGPTに貼り付けて画像を生成する(すべて **1536×1024ピクセル / 横長**)
2. 生成したPNGを次のフォルダに保存する(ファイル名はChatGPTが付けた名前のままでよい)
   `C:\Users\kokim\OneDrive\デスクトップ\画像フォルダ\各種サイト\AIサイト\ライブラリ\`
   保存したら `scripts/generate-site-images.js` の `MANIFEST` の `src` をそのファイル名に書き換える
3. サイト本体で変換コマンドを実行する(WebP化・リサイズが自動で走る)

   ```
   cd サイト運営\サイト本体
   node scripts/generate-site-images.js
   ```

   一部だけ作り直す場合はキー前方一致で絞り込める(例: `node scripts/generate-site-images.js hero category-chat`)
4. カテゴリを追加した場合は `lib/categoryMeta.js` の該当カテゴリに `image:` 行を追加する

**2026-08-28: 下記15枚は生成・変換・配置まで完了済み。**以降は差し替え時のプロンプト原本として使う。

## 出力サイズの対応表

| 用途 | 生成サイズ | サイト側の出力 | 実際の表示 |
|---|---|---|---|
| ヒーロー | 1536×1024 | `images/hero/home-hero.webp` ほか640/1024/1536w | 全幅・高さ220〜420pxでトリミング |
| バンド01 | 1536×1024 | `images/band/band-01.webp` ほか640/1024/1536w | 全幅・高さ180〜360pxでトリミング |
| バンド02 | 1536×1024 | `images/band/band-02.webp` ほか640/1024/1536w | 全幅・高さ180〜360pxでトリミング |
| カテゴリカード×12 | 1536×1024 | `images/category/〇〇.webp`(800w) | カード内・4:3でトリミング |

元画像とサイト側出力の対応は `scripts/generate-site-images.js` の `MANIFEST` が唯一の情報源。

## 全プロンプト共通の注意

- **文字・ロゴ・透かしは一切入れない**(日本語も英語も)。画面内のUIも判読可能な文字にしない
- 実在する企業名・製品名・ブランドロゴを描かない
- 明るく風通しのよい、白〜ライトグレー基調の空間。清潔感を優先する
- 人物を出す場合は日本人・自然な表情。極端な広角・強いパースをつけない

  ここには人物も家具も小物も一切置かない。あとから文字を重ねるための空間。
・主役は画面の右55%側にまとめる。

【トーン】
やわらかい自然光、白飛びしすぎない露出、低コントラスト、淡く上品な色調。
生活感が出すぎないよう、生活雑貨・食べ物・散らかった書類は写さない。

# 4〜15. カテゴリカード(12枚・各1536×1024)

カード内で**4:3にトリミング**され、幅は最大でも約380pxで表示される。そのため全12枚に共通して以下を守ること。

- 主役を画面中央に置き、左右端ギリギリに重要な要素を置かない(左右が少し切られる)
- 小さく表示されるので、要素を詰め込まず「ひと目で何のカテゴリか分かる」大きめのモチーフにする
- 12枚を並べたときにトーンが揃うよう、**すべて同じ白基調・自然光・低コントラスト**で統一する

各プロンプトの冒頭に、この共通指定を含めてある。

## 補足

- **OGP画像(`public/images/ogp.png`、1200×630)**は日本語テキストを含むため画像生成AIには向かない
  (文字が崩れる)。HTMLをChromiumで描画してスクリーンショットする方式で生成する。
  サイト名・キャッチコピーを変えたら `scripts/generate-ogp.js` の`TEXT`を書き換えて
  `npm run ogp` を実行し直すこと。
- **ロゴ(`images/logo.png` 512×512)・ファビコン各種**はマスコットのみで文字を含まないため、
  ジャンル変更による差し替えは不要。
- **マスコット12体+ネヴォミン(`public/images/mascot/*.svg`、全39ファイル)はSVGのまま流用**しており、
  差し替えは不要。キャラクターのデザイン自体を作り直したい場合は別途相談すること。
