# 企画の判定・通読判定の項目表

## 扱いの定義(ア・イ・ウ)

判定の担当は指摘を出すだけで、差し戻すかどうかは、この文書の「扱い」の列で統括が決める。差し戻しの回数は「アの差し戻し」だけを数える。

- ア 差し戻す: 直すと、読者に伝わる事実・条件・手順・結論が変わる指摘(法務の高・数字や事実の誤り・確認メモに無い具体的な数字等・記事の中の食い違い・論理の飛躍・矛盾・題や見出しや導入の約束に本文が答えていない・診断の結果や手順の食い違い・読者が実行できない指示)。差し戻したあとは、直した箇所に関係する判定だけをやり直す。
- イ まとめて直す: 形と書き方の指摘(字数・文の数・要素の数・部品の並び・絵文字や装飾・内部リンクの形・締めの文の数と型・同じ内容の重なり・見出しと本文の言い回し・見出しの型・語り・自己参照や予告の文・同じ語尾が続く文)。決まりは守るが、判定のやり直しには入れない。仕上げで、直す担当が1回でまとめて直す。
- ウ 差し戻さない(報告だけ): 第3層の過半数に満たない実行にだけ出た否定(第3層の採用の決まり)と、出典に関する指摘(出典の決まりで決めたとおり。sources が確認メモに無い不一致・根拠の飾り・言い切りの強さ・根拠の無さ・出典の種類や順位を含む。ア「確認メモに無い具体的な数字・料金・機能・モデル名・法律や規約の内容」だけはアのまま)と、企画書と原稿の食い違い(原稿は変えず、企画書の側を原稿に合わせて直す)。
- 迷う項目は「直すと、読者に伝わる事実・条件・手順・結論が変わるか」で決める。変わるならア、変わらないならイ。形・書き方の参考項目はイ。ウは第3層の過半数に満たない否定と、出典に関するものと、企画書と原稿の食い違いだけ。
- 1つの行に複数の扱いが書いてある行は、指摘の中身ごとの扱いである。法務の判定(高・中・低)の中身は変えない。
- この文書の表は、A(企画の判定)・B(通読判定)・E(多層の判定の全項目。E-1 は `nevora-pipeline-verifier.md` の第1層の全項目、E-2 は目で確かめること、E-3 は第1〜第6層の型、E-4 は編集長、E-5 は S4 レビューの区分、E-6 は法務)。同じ項目が表をまたぐときは、同じ扱いにしてある。

**この文書が、企画の判定・通読判定の項目表の正である。**回ごとの共通の指示(`サイト運営/記事データ/作成中/_共通の指示_第N回_段階1_企画の判定_…`・`_段階2_通読判定_…`)は、項目をここから写して使う(末尾の D の手順)。**項目の全文はこの文書だけに置く**(共通の指示に書き換えて持たない)。項目を足す・変えるときは、この文書だけを直す。見方の本文は次の3か所にあり、この表には書き写さない。
- 書き手の規則: `.claude/agents/writer.md`(規則番号で参照する)
- 目で確かめること(題・見出し・本文・部品の確かめ方): `.claude/agents/nevora-pipeline-verifier.md` の節「目で確かめること」。以下「確かめ表」と呼ぶ。`verify-article.js` の判定表(ブロッキング29項目)とは別で、ここでは通読判定の項目12・15・16・17が、その該当行を Yes/No にする
- 部品の数え方: `afterParagraph` は確かめ表の該当行と writer.md 規則32(a)。判定は `サイト運営/サイト本体/scripts/verify-article.js` が Yes になるかで見る(文面と食い違うときは verify-article.js を正とし、No にしない)

判定の約束(共通)
- 各項目は Yes/No。No は「行・どの規則か・何が足りないか」を1行で書く。点数はつけない。
- 判定の担当は、判定する対象を書いていない者とする。対象のファイルを直さない(書いてよいのは判定のファイル1つだけ)。
- 2回目以降は、最初の回で No だった項目を固定し、項目を足さない。ただし、直しで新しく崩れた箇所は No にする。アの差し戻しのあとは、直した箇所に関係する項目だけをやり直し、直った/直っていないを No の理由に書く(イは仕上げでまとめて直し、判定のやり直しには入れない)。
- 診断の結果の文(`desc`)が地の文と同じ内容でも No にしない(規則32(b))。
- **出典を理由に No にしてよいのは1つだけ**: 「記事にある具体的な数字・料金・機能・モデル名・法律や規約の内容が、確認メモ(sources.md)に無い」(出典の決まり4。本文を書き終えたあとの確かめを済ませた記事を見る。確かめを済ませても確認メモに無い数字等が本文に残っていれば指摘する)。次は報告には書くが No にしない(差し戻し回数に数えない): 地の文に出典名や機関名がある/伝聞の語尾/言い換えが原文に近い・原文より強い/根拠が読者に見える所に無い/(新しい原稿の本文には出典の印〔`%%出典:…%%`〕を書かない。出典は記事の末尾の出典の欄だけに載せる。既存の原稿に `%%` が残っていても、コードが画面に出さないので、No にしない)/企画書の出典の欄の形/出典の種類や順位。「根拠を超えた断定」「根拠が無い主張」も出典・根拠を理由とするので、No にせず報告に残す。機関や提供元の見解・方針そのものを伝える文では機関名を主語にしてよい。
