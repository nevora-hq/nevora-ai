# quadrantチャート誤読リスク監査

対象: `type: "quadrant"`チャートを持つ全記事(確定稿・公開済み)。

背景: 軸の値が高いほど高額=悪い(費用など)のに◎がつくと「優れている」と誤読されるリスクがある。`lib/posts.js`の`renderQuadrantChartHtml`では、◎○△の評価記号を廃止して中立的な高低表現(「高い/中程度/低い」)をデフォルトにした(CONTRIBUTING.md §20参照)。この変更により記号由来の誤読リスクは全記事で自動的に解消される。

以下は、軸の意味が「高い=悪い(費用・価格など)」であるためレンダラー修正後も文言(「高い/中程度/低い」)だけでは実感に合わない可能性がある記事の一覧。**修正はユーザーの確認後に行う(本監査は報告のみ)。**

## 誤読リスク低(軸の値が高い=良い、またはニュートラルな属性)

両軸が「高い=一般に好ましい」か、良し悪しを伴わない特性の強弱なら、記号除去・中立表現化により誤読リスクは実質的に解消するので、追加対応は不要。軸ラベルに方向の注記(低い←→高い)があれば足りる。

## まとめ

- 記号(◎○△)由来の誤読リスクは`lib/posts.js`の修正により解消する(コード修正のみで対応、記事側の追加修正は不要)。
- 費用・価格軸を持つ記事は、`xNote`/`yNote`で具体的な文言を追加すると更に親切だが、軸ラベル自体に方向性の説明がある記事は優先度低。
