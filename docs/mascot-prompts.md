# マスコット 生成プロンプト集(NEVORA AI)

NEVORAの世界観(「〇〇ミン」たち)を、AIサイト用に作り直すための画像生成プロンプト。
ブランドカラーはブルー **#1e5fa8**。

## 体系

| 役割 | 名前 | 用途 |
|---|---|---|
| メインマスコット | **アイミンちゃん** | ロゴ・ファビコン・トップページの挨拶・記事末尾。サイト全体の案内役 |
| カテゴリ担当(12体) | チャミン/エガミン/ムビミン/カキミン/コードミン/ジドウミン/カセギミン/クラベミン/マナミン/ビズミン/クラシミン/ニューミン | 各カテゴリページ・該当記事の吹き出しコメント |

各キャラは3ポーズを持つ(`lib/categoryMascot.js` の仕様)。

| ポーズ | ファイル名の接尾辞 | 使われる場所 |
|---|---|---|
| 挨拶 | `-normal` | 記事冒頭・カテゴリカード・ロゴ |
| 補足 | `-research` | 記事中盤の補足コメント |
| まとめ | `-matome` | 記事末尾のまとめコメント |

## 生成・納品の手順

1. 下記プロンプトで **1024×1024ピクセル / 背景透過のPNG** を生成する
   (透過が指定できない場合は**真っ白な背景**で生成する。こちらで透過処理をする)
2. 次のフォルダに保存する
   `C:\Users\kokim\OneDrive\デスクトップ\画像フォルダ\各種サイト\AIサイト\マスコット\`
3. 保存したら知らせる。以下はこちらで対応する
   - `public/images/mascot/` への配置と `lib/categoryMascot.js` の参照差し替え
   - ロゴ・ファビコン一式(`logo.png` 512×512 / `logo-mark.png` 128×128 /
     `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` 180×180 /
     `favicon-16・32・48.png` / `favicon.ico`)の書き出し

> **メインマスコットの3ポーズだけ先に作れば、ロゴとファビコンは差し替えできる。**
> カテゴリ12体は後追いで問題ない(現在は旧デザインのSVGが表示されている)。

## 共通のアートスタイル(全プロンプトに含めてある)

既存のNEVORAマスコットと世界観を揃えるための指定。

- フラットなベクターイラスト。陰影・グラデーション・質感は付けない
- 太さの均一な輪郭線(体の高さに対して約2.5%の太さ)、角は丸く
- 顔は極端に簡素:黒い丸い点の目(小さな白いハイライト付き)、頬に楕円の赤み、細い曲線の口
- 手足は輪郭線と同じ太さの短い曲線のみ(指・関節は描かない)
- 足元に薄い楕円の影
- 背景は完全な透過
- 3Dレンダリング・厚塗り・アニメ調の陰影・写実表現にしない

## 補足

- 現在の `public/images/mascot/*.svg`(旧・美容サイトのしずく型13体×3ポーズ)は、
  差し替えが済むまでそのまま表示される。段階的に置き換えて問題ない。
- 画像生成AIは同一キャラクターを完全に再現するのが苦手なため、
  **1体につき3ポーズを1つの会話の中で続けて生成する**と一貫性が保ちやすい。
  それでもブレる場合は、1-Aで生成した画像を添付して「この画像のキャラクターのまま、
  ポーズと表情だけ変えて」と指示する。
- ロゴ用途では小さく表示されるため、細部を描き込みすぎないこと。
  16×16pxのファビコンでも形が判別できるシルエットであることを優先する。
