# マスコット造形仕様(NEVORA AI)

NEVORAの世界観(「〇〇ミン」たち)をAIサイト用に作り直したマスコットの造形仕様。
ブランドカラーはブルー **#1e5fa8**。

## 体系

| 役割 | 名前 | 用途 |
|---|---|---|
| メインマスコット | **アイミンちゃん** | ロゴ・ファビコン・トップページの挨拶・記事末尾。サイト全体の案内役 |
| カテゴリ担当(12体) | チャミン/エガミン/ムビミン/カキミン/コードミン/ジドウミン/カセギミン/クラベミン/マナミン/ビズミン/クラシミン/ニューミン | 各カテゴリページ・該当記事の吹き出しコメント |

各キャラは3ポーズを持つ(`lib/categoryMascot.js` の仕様)。

| ポーズ | ファイル名の接尾辞 | 使われる場所 |
|---|---|---|
| 挨拶 | `-normal` | 記事冒頭・カテゴリカード・ロゴ |
| 補足 | `-research` | 記事中盤の補足コメント |
| まとめ | `-matome` | 記事末尾のまとめコメント |

## 実装方法(2026-08-28変更: 画像生成AI → SVGで実装)

当初は画像生成AIでPNGを作る想定だったが、**マスコットは`scripts/generate-mascots.js`が
SVGとして生成する方式に切り替えた。**このファイルは、その造形の仕様書として残している。

```
cd サイト運営\サイト本体
node scripts/generate-mascots.js            # 13体 × 3ポーズ + 顔アップ = 40ファイル
node scripts/generate-mascots.js aimin      # keyの前方一致で絞り込み
node scripts/generate-brand-assets.js       # ロゴ・ファビコン一式をSVGから書き出し
```

- 出力先は `サイト本体\public\images\mascot\<key>-<pose>.svg`
- 体・顔・手足のジオメトリは全キャラ共通。**輪郭色・体の塗り・持ち物だけ**が違う
- `aimin-face.svg`(顔+しっぽの切り出し)はロゴマークとファビコン専用。
  `generate-brand-assets.js` が `logo.png` / `logo-mark.png` / `favicon-16・32・48.png` /
  `icon-192・512.png` / `apple-touch-icon.png` / `favicon.ico` を書き出す
- **OGP画像はここでは作らない。** `scripts/generate-ogp.js` に一本化している
  (複数スクリプトが同じファイルを書くと、実行順で結果が上書きされるため)
- 造形を変えたいときは、下記の仕様を更新した上で `generate-mascots.js` の
  該当パーツ(`BODY_PATH` / `eyes` / `mouth` / `arms` / `MOTIFS`)を書き換える。
  SVGを直接編集しても次回の生成で上書きされる

## 共通のアートスタイル

既存のNEVORAマスコットと世界観を揃えるための指定(`generate-mascots.js`の共通パーツに実装済み)。

- フラットなベクターイラスト。陰影・グラデーション・質感は付けない
- 太さの均一な輪郭線(体の高さに対して約2.5%の太さ)、角は丸く
- 顔は極端に簡素:黒い丸い点の目(小さな白いハイライト付き)、頬に楕円の赤み、細い曲線の口
- 手足は輪郭線と同じ太さの短い曲線のみ(指・関節は描かない)
- 足元に薄い楕円の影
- 背景は完全な透過
- 3Dレンダリング・厚塗り・アニメ調の陰影・写実表現にしない

　1つ浮いている。体には接していない。

【スタイル】
フラットなベクターイラスト。陰影・グラデーション・質感・光沢は一切付けない。
線と塗りだけで構成する。かわいらしく、親しみやすく、清潔感のある印象。

【描かないもの】
背景・文字・ロゴ・透かし。陰影やグラデーション。歯・舌・鼻・耳・眉。

## 12体共通の仕様

`generate-mascots.js` の `CHARACTERS` に上表の値(key・name・color・soft・blush・motif)を
持たせてあり、下記の造形で3ポーズぶんが自動生成される。
`-normal` は持ち物を持った挨拶、`-research` は虫めがね、`-matome` はノートで共通。

```
【造形定義】フラットなベクターイラストのマスコットキャラクター1体。正面向き・中央配置。

【キャラクター】
・名前は〔キャラクター名〕。丸みのある「吹き出し(チャットバルーン)」の形をした体。
　角が大きく丸い正方形に近いシルエットで、左下の端に小さな三角のしっぽ(吹き出しの先)がある。
・体の塗りは〔体の塗り色〕。
・輪郭線は〔輪郭線の色〕の均一な太さの線で、体の高さの約2.5%の太さ。角は丸く。
・頭のてっぺんの少し右寄りに、輪郭線と同じ色の小さな四芒星が1つ浮いている。
・顔は体の中央よりやや下。黒い丸い点の目が2つ、それぞれ左上に小さな白いハイライト。
　両ほほに輪郭線と同系色のうすい楕円の赤み。口は下向きに緩く曲がった短い線で、
　やさしく微笑んでいる。
・右手に〔持ち物〕を持っている。持ち物は輪郭線と同じ色の線で簡素に描き、
　塗りは体と同じ淡い色にする。キャラクターより小さく、体の右前あたりに配置する。
・左手は体の左から出た短い曲線1本。足は体の下から出た短い曲線2本。指や関節は描かない。
・足元に、輪郭線と同系色のうすい楕円の影を1つ。

【スタイル】
フラットなベクターイラスト。陰影・グラデーション・質感・光沢は一切付けない。
線と塗りだけで構成する。12体のキャラクターを並べたときに同じシリーズに見えるよう、
体のかたち・線の太さ・顔の作りは完全に統一すること。

【描かないもの】
背景・文字・ロゴ・透かし。陰影やグラデーション。歯・舌・鼻・耳・眉。
```

## 補足

- 旧・美容サイトのしずく型マスコット(13体×3ポーズ)は2026-08-28に削除済み。
- ロゴ用途では小さく表示されるため、細部を描き込みすぎないこと。
  16×16pxのファビコンでも形が判別できるシルエットであることを優先する
  (このため、ファビコンには手足・浮いた星を持たない`aimin-face.svg`を使っている)。
- 各キャラの名前・担当カテゴリの対応は `サイト本体\lib\categoryMascot.js` が実装の正。
