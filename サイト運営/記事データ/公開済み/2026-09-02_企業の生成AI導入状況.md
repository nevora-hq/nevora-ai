「もう多くの会社が、仕事で生成AIを使っているらしい」と聞いて、自分の職場を思い浮かべ、少し落ち着かなくなったことはありませんか🤔 取引先との雑談やニュースで耳にして、帰ってから「企業 生成AI 導入状況」と調べた人もいるかもしれません。

ところが検索すると、34.5%と出るページもあれば、86.4%と出るページもあります。上司に「他社はどうなの」と聞かれて数字を探している人も、自分だけ個人で使っていて会社としてはどうなのか気になる人も、同じ数字の前で止まっているのかもしれません。「日本は海外より遅れているらしい」と聞いて調べ直している人も、同じかもしれません。この記事では、2つの数字の読み方と、日本と海外で差が残る所、他社と比べずに自社の位置を言う見方を、詳しく見ていきましょう。

## 企業の生成AI導入状況を調べたら、数字が割れていたとき

調べていて、34.5%と86.4%のように大きく違う数字が並ぶと、どちらを信じればよいのか迷うかもしれません。自分はどの場面で数字を探しているのでしょうか。

上司に「遅れているのか」と聞かれたとき、自分だけ個人で使っていて位置が気になるとき、会社に決まりがあるのかさえ分からないとき。どれに近いかで、読む所が変わってきます。まず、2つの数字がそもそも何の数字なのかから見てみましょう。

## 34.5%と86.4%は、何を何で割った数字か

検索結果で2つの数字が並んだときは、どちらかが間違っているわけではなく、何を数えて、何で割ったかが違います。聞き方と数え方で、同じ「導入状況」でも数字の見え方は変わります。

### 34.5%は、誰に何を聞いた数字か

34.5%は、帝国データバンクが2026年3月に全国の企業へ聞いた調査の数字です。有効回答1万312社のうち、生成AIを業務で「活用している」と答えた企業の割合にあたります。次の表は、同じ調査の回答のうち、割合が公表されているものを並べたものです。

| 回答 | 割合 | 34.5%に入るか |
| --- | --- | --- |
| 非常に活用している | 4.4% | 入る |
| やや活用している | 30.2% | 入る |
| あまり活用していない | 13.6% | 入らない |
| ほとんど活用していない | 23.3% | 入らない |
| いまは活用していないが、今後の活用を検討している | 14.2% | 入らない |
| 活用を禁止している | 0.4% | 入らない |

聞いた相手は全国2万3,349社で、回答率は44.2%です。34.5%は、答えた企業の中での割合になります。規模別では、大企業46.5%、中小企業32.4%、小規模企業28.0%でした。

34.5%は「非常に」と「やや」の合計で、大半は「やや活用している」の30.2%です。34.5%に入らない企業の中にも、今後の活用を検討している企業が14.2%あるので、入らない企業がすべて使う予定のない企業だとは読めません。「活用している」という数字を見たら、「やや」まで含んだ数字かどうかを確かめるのが先です。

### 86.4%は、何で割った数字か

86.4%は、総務省の情報通信白書の令和8年版に載った企業向けアンケートの数字です。何らかの業務で生成AIを使っていると答えた割合で、==分母は、方針の設問で「わからない」と答えた回答を除いた残り==です。34.5%と並べると、数えたものも分母も違うことが見えてきます。

| | 34.5% | 86.4% |
| --- | --- | --- |
| 調査 | 帝国データバンク(2026年3月) | 総務省 情報通信白書 令和8年版(2025年度企業向け調査) |
| 数えたもの | 業務で「活用している」(非常に、またはやや)と答えた企業 | 何らかの業務で生成AIを使っていると答えた回答 |
| 分母 | 有効回答1万312社の全部 | 方針の設問で「わからない」と答えた回答を除いた分 |

![青とオレンジの2枚のクリップボードが机に並び、左はチェックボックスが4つ、右は6つ描かれているイラスト。左の用紙を指さす手が添えられている](/images/articles/企業の生成AI導入状況_body1.webp)

どちらも、日本の全企業の割合そのものではありません。アンケートの回答の中での割合なので、自社が遅れているかを決める合格ラインにはしないでください。数字を見るときは、^^何を聞いた調査か、何で割った数字かを先に確かめましょう^^

### 同じ白書の数字も、年度で割れるのか

年度の違いでも、数字は割れます。次の表は、同じ白書にある、生成AIを一つ以上の業務で利用している割合を国別に並べたものです。

| 国 | 2025年度企業向け調査 | 2024年度企業向け調査(参考) |
| --- | --- | --- |
| 日本 | 86.4% | 55.2% |
| 米国 | 90.9% | 90.6% |
| ドイツ | 91.6% | 90.3% |
| 中国 | 98.1% | 95.8% |

日本の86.4%は、前年度の企業向け調査では55.2%でした。他の3か国は前年度も90%を超えていて、日本との差が縮まっています。数字を人に伝えるときは、聞き方と分母に加えて、何年度の調査かも添えてください。

## 方針の割合と、使われ方の深さは別の数字

数字の読み方が分かっても、もう1つ迷う所があります。会社に方針があるかと、実際にどこまで使われているかは、別の設問への答えだからです。方針ありの割合だけを他社と並べても、使われ方の深さまでは分かりません。

### 方針ありの中身は、どんな内訳か

会社として生成AIを使う方針があるかを聞いた設問では、「積極的に活用する方針である」と「活用する領域を限定して利用する方針である」を合わせて68.9%でした。前の年度は49.7%で、今回は大企業が74.0%、中小企業が58.1%です。日本全体の5つの回答の内訳は、次のとおりです。

| 回答(日本・2025年度) | 割合 |
| --- | --- |
| 積極的に活用する方針である | 30.1% |
| 活用する領域を限定して利用する方針である | 38.8% |
| 利用を禁止している | 3.5% |
| 方針を明確に定めていない | 20.2% |
| わからない | 7.4% |

「方針を明確に定めていない」は20.2%、「利用を禁止している」は3.5%で、自社に決まりが見当たらないときも、同じ状況の回答はあります。ただし方針の有無と実際の使われ方は、別の設問です。

### 自社の規模だと、決まりのない割合はどう違うか

次の表は、日本の企業を規模で分けたときの、方針の設問への回答です。

| 回答(日本・2025年度) | 大企業 | 中小企業 |
| --- | --- | --- |
| 積極的に活用する方針である | 34.6% | 20.4% |
| 活用する領域を限定して利用する方針である | 39.4% | 37.7% |
| 利用を禁止している | 4.5% | 1.2% |
| 方針を明確に定めていない | 15.0% | 31.5% |
| わからない | 6.5% | 9.3% |

大企業の74.0%と中小企業の58.1%の差は、ほとんどが「積極的に活用する方針である」の差で、34.6%と20.4%です。「活用する領域を限定して利用する方針である」は、39.4%と37.7%でほぼ同じ。中小企業では、「方針を明確に定めていない」の31.5%が、「積極的に活用する方針である」の20.4%より多くなっています。自社に決まりが見当たらないときは、規模の近い列の「方針を明確に定めていない」を見ると、同じ状況の回答がどれだけあるかが分かります。

> ⚠️ 注意
> 同じ状況の回答があっても、決まりを確かめなくてよいことにはなりません。

### 中小企業で決まりが見当たらないとき、誰に何を聞くか

日本の中でも、「組織的な取組はない」は大企業で18.1%、中小企業で45.6%と割れます。自社が中小企業で決まりが見当たらないなら、上司か経営層に聞くことを、次の2点に絞ってみてください。

| 聞くこと | 手がかり |
| --- | --- |
| 生成AIについて、部署にやることや目標は示されているか | 中小企業で最も高かった回答が、「経営幹部から各部署に対して実施事項や達成目標が提示されている」だった |
| 生成AIのことを聞く先は、誰か | 他の3か国で目立った回答に、「取組を推進する部署や責任者が明確になっている」があった |

白書は、中小企業のAI活用ではトップダウンの関与がキーポイントになっていることがうかがえる、とまとめています。

> ⚠️ 注意
> 聞く先が分からないまま、入れてよい情報を推測するのは避けてください。

### 海外と比べると、差が残っているのはどこか

年度の表のとおり、利用の差は縮まりました。いま差が目立つのは、会社として決めて進めているかのほうです。ここでいう海外は、調査の対象になっている米国・ドイツ・中国の3か国で、次の表は2025年度調査の2つの設問を国別に並べたものです。

| 国 | 方針を明確に定めていない | 組織的な取組はない |
| --- | --- | --- |
| 日本 | 20.2% | 27.0% |
| 米国 | 7.8% | 1.4% |
| ドイツ | 9.7% | 4.9% |
| 中国 | 2.3% | 2.6% |

方針を明確に定めていない企業は、日本の20.2%に対して、他の3か国が2.3〜9.7%です。「組織的な取組はない」も日本は27.0%で、他の3か国の1.4〜4.9%を上回ります。こちらは利用を禁止している会社を除いた割合なので、方針の設問とは分母が違い、2つを引き算はできません。

> 💡 NEVORAポイント
> 「日本は遅れている」と言われたら、利用の差は縮まったこと、残るのは==決めて進めているかの差==であることを、年度を添えて伝えてみてください。

### 方針があっても、使われ方は別の数字なのか

使われ方の設問は、業務ごとに「従業員が個人作業の効率化で活用している」「部署内の特定業務で活用している」「業務プロセスがAI中心に変更されている」のほか、「未導入」「わからない」「社内に該当業務はない」から選ぶ形です。方針ありの企業に限った数字とは限らないので、方針の割合とは引き算せず、別々に読みます。「業務ごとの、会社での使われ方」の図の4列を足して100%にならないのは、残りに「わからない」などがあるためです。

議事録・メール作成補助と営業・販売は、個人の作業の効率化が最も多くなっています。社内ヘルプデスクと経理・財務は部署内の特定の業務が多めですが、この2つは未導入が最多で、28.8%と30.8%でした。仕事の流れがAI中心に変わった回答は、4つとも1割強までにとどまります。

### 図にない9つの業務は、どこまで進んでいるか

図の4つ以外の業務も、同じ設問で聞かれています。次の表は、その9つの業務の回答です。

| 業務 | 個人作業で活用 | 部署内の特定業務で活用 | 業務プロセスがAI中心に変更 | 未導入 |
| --- | --- | --- | --- | --- |
| 研究・商品開発 | 19.3% | 22.9% | 7.6% | 27.4% |
| 調達 | 14.3% | 16.7% | 7.0% | 35.0% |
| 製造・生産 | 16.7% | 19.7% | 6.0% | 28.4% |
| マーケティング・広報 | 18.1% | 23.9% | 7.4% | 27.6% |
| カスタマーサポート | 12.7% | 22.1% | 9.9% | 29.4% |
| 経営 | 16.7% | 21.3% | 8.0% | 28.2% |
| 人事 | 15.1% | 20.3% | 5.6% | 35.4% |
| 法務 | 13.7% | 22.7% | 6.2% | 32.8% |
| 社内システム開発・運用 | 17.9% | 24.5% | 8.0% | 26.6% |

この9つでも、業務プロセスがAI中心に変わった回答は5.6%から9.9%にとどまり、図の4つを加えた13の業務で最も高いのは、社内ヘルプデスクの11.9%です。未導入が最も多いのは人事の35.4%で、調達が35.0%、法務が32.8%と続きます。

未導入の列だけで、自社の遅れを決めないでください。同じ設問には「わからない」もあり、人事では19.7%、法務では20.5%で、この回答は各行の残りに入っています。自分の仕事に近い行を1つ選び、個人・部署・仕事の流れのどこまで進んでいるかを見ておくと、自社の位置を言うときの材料になります。

使っているかどうかより、誰がどこまで使っているかで見たほうが、自社と並べやすくなります。では、自社はどこにいるのでしょうか🤔

## 自社の位置は、何を見れば言えるのか

自社の位置は、「使っているか」ではなく「誰がどこまで使っているか」で言えます。調査の使われ方の区分を借りて、まだ誰も使っていない・個人の作業で使っている・部署の特定の仕事で使っている・仕事の流れがAI前提に変わっている、の4つに分けてみましょう。これは調査そのものの区分ではなく、この記事の整理です。

「自社の位置と、次の一段」の診断で、使われ方と会社の決まりを答えると位置が出ます。禁止か不明のときは、位置より先に決まりの確認です。位置ごとの次の一段は、次の表のとおりです。

| 位置 | 次の一段 |
| --- | --- |
| まだ誰も使っていない | 決まりの範囲で、次の会議のあとに議事録のたたき台を頼む |
| 個人の作業で使っている | 頼む文を1つに決めて、毎回その文で頼む |
| 部署の特定の仕事で使っている | その仕事の、頼んでから使えるまでの時間を数回分メモする |
| 仕事の流れが変わっている | 人が最後に確かめる所を1つ書き出す |

### 最初に頼む業務は、何を基準に選ぶのか

数字で見ると、個人作業で活用している回答は議事録・メール作成補助が35.2%で、4つの業務の中で最も多くなっています。効果を感じる回答も72.3%で、次点の社内ヘルプデスクの42.7%を大きく上回ります。効果の割合は活用とは別の設問なので、引き算はしないでください。

34.5%の調査で、生成AIを活用している企業3,560社に主な活用業務を聞いた結果が、次の表です。

| 主な活用業務 | 割合 |
| --- | --- |
| 文章の作成・要約・校正 | 45.1% |
| 情報収集 | 21.8% |
| 企画立案時のアイデア出し | 11.0% |
| データの集計・分析 | 7.4% |
| コード生成などのプログラミング支援 | 5.9% |

この割合は活用している企業3,560社の中でのもので、全企業の割合ではありません。総務省の調査では「議事録・メール作成補助」、この調査では「文章の作成・要約・校正」が、それぞれ最上位に出ています。同じ調査には、活用企業の86.7%が「効果あり」と答えた数字もありますが、これは86.4%とは別の質問への答えです。最初の1件の頼み方は、[生成AIを使ったことがある人は何割｜日本の数字と最初に頼む1件](/posts/2026-09-09_生成AIの利用経験率と仕事の進め方)にまとめています。

### 禁止か不明のときは、先に何を聞くか

禁止か不明の位置にいるときは、位置の言い方より先に、会社の決まりを確かめます。聞き方は[社内で生成AIを使い始める進め方](/posts/2026-09-01_社内で生成AIを使い始める進め方)に、入れてよい情報の線は[AIに入力してはいけない情報｜貼る前に見る所と、設定でも残るもの](/posts/2026-09-08_AIに入力してはいけない情報)にあります。

### 頼んだ結果が使えないときは、どこを見直すか

頼んだ結果が使えなくても、自社だけが遅れている証拠にはなりません。見直し方は[AIで議事録を作る手順｜会議中に仕込む一言と送信前の5か所](/posts/2026-09-04_AIで議事録を作る)を読んでみてください。

## 次の会議のあと、最初に1つだけ試すこと

遅れているかを他社の割合だけで決めることはできず、自社で誰がどこまで使っているかを言えれば、次の一段を選べます。

- 自社の位置を、まだ誰も使っていない・個人の作業・部署の仕事・仕事の流れの変化のどれかで言う
- 禁止されているか決まりが分からないときは、先に1つ聞く
- 位置に合う次の一段を、1つだけ選ぶ
- 他社の数字は、聞き方と分母を添えて人に伝える
