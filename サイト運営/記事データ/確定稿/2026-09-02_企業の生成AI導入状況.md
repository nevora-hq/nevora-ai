「もう多くの会社が、仕事で生成AIを使っているらしい」と聞いて、自分の職場を思い浮かべ、少し落ち着かなくなったことはありませんか？🤔 取引先との雑談やニュースで耳にして、帰ってから「企業 生成AI 導入状況」と調べる人もいると思います。

ところが調べてみると、34.5%と出るページもあれば、86.4%と出るページもあります。上司に「他社はどうなの」と聞かれて数字を探している人も、自分だけ個人で使っていて会社としてはどうなのか気になる人も、同じ数字の前で止まっているのかもしれません。

割れる理由の1つは、2つの数字が別の質問への答えで、数え方や分母が違うことです。そこが分かると、他社の割合に頼らず、自社で誰がどこまで使っているかを言えるようになります。

## 企業の生成AI導入、34.5%と86.4%で数字が割れるのはなぜか

検索結果で2つの数字が並んだときは、どちらかが間違っているわけではなく、何を数えて、何で割ったかが違います。34.5%を出した調査では、あまり・ほとんど活用していない企業が約4割あり、86.4%とは見える景色がかなり違います。聞き方と数え方で、数字の見え方は変わるのです😅

34.5%は、帝国データバンクが2026年3月に全国の企業へ聞いた調査の数字です。有効回答1万312社のうち、生成AIを業務で「活用している」と答えた企業の割合にあたります。規模別では、大企業46.5%、中小企業32.4%、小規模企業28.0%でした。

86.4%は、総務省の情報通信白書(令和8年版)に載った企業向けアンケートの数字です。何らかの業務で生成AIを使っていると答えた割合で、==分母は、方針の設問で「わからない」と答えた回答を除いた残り==です。34.5%と並べると、数えたものも分母も違うことが見えてきます。

| | 34.5% | 86.4% |
| --- | --- | --- |
| 調査 | 帝国データバンク(2026年3月) | 総務省 情報通信白書 令和8年版(2025年度企業向け調査) |
| 数えたもの | 業務で「活用している」(非常に、またはやや)と答えた企業 | 何らかの業務で生成AIを使っていると答えた回答 |
| 分母 | 有効回答1万312社の全部 | 方針の設問で「わからない」と答えた回答を除いた分 |

![青とオレンジの2枚のクリップボードが机に並び、左はチェックボックスが4つ、右は6つ描かれているイラスト。左の用紙を指さす手が添えられている](/images/articles/企業の生成AI導入状況_body1.webp)

どちらも、日本の全企業の割合そのものではありません。アンケートの回答の中での割合なので、自社が遅れているかを決める合格ラインにはしないでください。数字を見るときは、^^何を聞いた調査か、何で割った数字かを先に確かめましょう^^

## 活用する方針ありは約7割、仕事の流れの変更は1割強まで

会社として生成AIを使う方針があるかを聞いた設問では、「積極的に活用する方針である」と「活用する領域を限定して利用する方針である」を合わせて68.9%でした。前の年度は49.7%で、今回は大企業が74.0%、中小企業が58.1%です。日本全体の5つの回答の内訳は、次のとおりです。

| 回答(日本・2025年度) | 割合 |
| --- | --- |
| 積極的に活用する方針である | 30.1% |
| 活用する領域を限定して利用する方針である | 38.8% |
| 利用を禁止している | 3.5% |
| 方針を明確に定めていない | 20.2% |
| わからない | 7.4% |

「方針を明確に定めていない」は20.2%、「利用を禁止している」は3.5%で、自社に決まりが見当たらないときも、同じ状況の回答はあります。ただし方針の有無と実際の使われ方は、別の設問です。

使われ方の設問は、業務ごとに「従業員が個人作業の効率化で活用している」「部署内の特定業務で活用している」「業務プロセスがAI中心に変更されている」のほか、「未導入」「わからない」「社内に該当業務はない」から選ぶ形で、方針ありの企業に限った数字とは限りません。方針の割合とは引き算せず、別々に読みます。図の4列を足して100%にならないのは、残りに「わからない」などがあるためです。

議事録・メール作成補助と営業・販売は個人の作業の効率化が最も多く、社内ヘルプデスクと経理・財務は部署内の特定の業務が多めです。ただ、この2つは未導入が最多で、28.8%と30.8%でした。仕事の流れがAI中心に変わった回答は、4つとも1割強までにとどまります。

![3人の人物が縦線で区切られて並び、頭上のドットが左から7つ・3つ・1つと減っていくイラスト](/images/articles/企業の生成AI導入状況_body2.webp)

使っているかどうかより、誰がどこまで使っているかで見たほうが、自社と並べやすくなります。では、自社はどこにいるのでしょうか🤔

## 自社の位置は、誰がどこまで使っているかで言える

自社の位置は、「使っているか」ではなく「誰がどこまで使っているか」で言えます。調査の使われ方の区分を借りると、まだ誰も使っていない・個人の作業で使っている・部署の特定の仕事で使っている・仕事の流れがAI前提に変わっている、の4つに分けられます(調査そのものの区分ではありません)。使われ方と会社の決まりを答えると位置が出ますが、禁止か不明の人は位置より先に決まりの確認です。位置ごとの次の一段は、表のとおりです。

| 位置 | 次の一段 |
| --- | --- |
| まだ誰も使っていない | 決まりの範囲で、次の会議のあとに議事録のたたき台を頼む |
| 個人の作業で使っている | 頼む文を1つに決めて、毎回その文で頼む |
| 部署の特定の仕事で使っている | その仕事の、頼んでから使えるまでの時間を数回分メモする |
| 仕事の流れが変わっている | 人が最後に確かめる所を1つ書き出す |

最初の業務は、議事録・メール作成補助がおすすめです。調査でも活用が約7割と最も多く、効果を感じる回答も72.3%と、ほかの業務から離れています。効果の割合は活用とは別の設問なので、引き算はしないでください。

どの位置でも、会社の中身を入れる前に、決まりを確かめるのが先です。禁止されているなら、試さずに、どんな条件なら使えるかを上司か担当部署に聞くところまでにしてください。決まりが無い、または知らないときも同じ内容を聞き、答えが出るまでに試す場合は、社外に出ても困らない自分のメモにとどめるのが無難です。入れてはいけない情報の考え方は、[生成AIに入力してはいけない情報:貼る前に「その文章の行き先」を3つで考える](/posts/2026-09-08_AIに入力してはいけない情報)にまとまっています。

> 💡 NEVORAポイント
> 聞くときは、「会社の資料や議事録の内容を生成AIに入れてよいか、==条件があれば教えてください==」と1つだけ聞きます。

頼んだ議事録のたたき台が使えなかったときは、[AIで議事録を作る手順｜会議の最後の1分から送信前の見直しまで](/posts/2026-09-04_AIで議事録を作る)が参考になります。社内で広げる段取りまで考えたい人は、[社内で生成AIを使い始める進め方｜許可の一文と最初に頼む1件](/posts/2026-09-01_社内で生成AIを使い始める進め方)も読んでみてください。

## 最初の一歩は、位置に合う次の一段を1つだけ

遅れているかを他社の割合だけで決めることはできず、自社で誰がどこまで使っているかを言えれば、次の一段を選べます。

- 自社の位置を、まだ誰も使っていない・個人の作業・部署の仕事・仕事の流れの変化のどれかで言う
- 禁止されているか決まりが分からないときは、先に1つ聞く
- 位置に合う次の一段を、1つだけ選ぶ
- 他社の数字は、聞き方と分母を添えて人に伝える

> 💡 NEVORAポイント
> 次の会議のあと、自社の位置の「次の一段」を==1つだけ==やってみてください。決まりが分からないときは、先に聞く一文から。
