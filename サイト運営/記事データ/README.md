# 記事データ

記事Markdownの置き場。フォルダごとに記事のライフサイクルを表す。

| フォルダ | 用途 |
|---|---|
| `キーワード調査` | keyword-researcherの調査結果 |
| `確定稿` | 編集長が承認した公開可能な記事。ビルド時に`サイト本体/content/articles`へ同期される |
| `公開待ち` | 公開キューに入っている記事 |
| `公開済み` | 公開済みの記事(確定稿と同様にビルド対象) |
| `振り返り` | 公開後のマーケター分析・振り返り |
| `非公開アーカイブ` | 取り下げ・差し替えで非公開にした記事 |

`サイト本体/content/articles` はビルド成果物のため直接編集しないこと(`scripts/sync-content.js`が再生成する)。
