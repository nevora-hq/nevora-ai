# 記事データ

記事Markdownの置き場。フォルダごとに記事のライフサイクルを表す。

| フォルダ | 用途 |
|---|---|
| `キーワード調査` | keyword-researcherの調査結果 |
| `作成中` | 作りかけの記事の作業フォルダ(記事ごとに1つ。企画書・原稿・確認メモ・判定の記録・画像のプロンプト)。git に入れない。公開したあと、その記事のフォルダは消す |
| `公開待ち` | 最後の判定を通った公開する版の1ファイル(`publishAt` は置いて push する時点で必ず入っている)。公開の処理が公開済みへ移す。サイトには出ない |
| `公開済み` | 公開済みの記事。ビルド時に`サイト本体/content/articles`へ同期される(サイトに出る記事のすべて) |
| `振り返り` | 公開後のマーケター分析・振り返り |
| `非公開アーカイブ` | 取り下げ・差し替えで非公開にした記事 |

記事の状態は 作成中 → 公開待ち → 公開済み の3種類で、「確定稿」という置き場は無い(詳細は `.claude/skills/run-article-production/SKILL.md` の「記事の状態と置き場」)。

`サイト本体/content/articles` はビルド成果物のため直接編集しないこと(`scripts/sync-content.js`が再生成する)。
